Documentation for Voice AI API

[**📄️Create Agent Action** \\
Create a new action for a voice AI agent. Actions define specific behaviors and capabilities for the agent during calls.](https://marketplace.gohighlevel.com/docs/ghl/voice-ai/create-action)[**📄️Update Agent Action** \\
Update an existing action for a voice AI agent. Modifies the behavior and configuration of an agent action.](https://marketplace.gohighlevel.com/docs/ghl/voice-ai/update-action)[**📄️Get Agent Action** \\
Retrieve details of a specific action by its ID. Returns the action configuration including actionParameters.](https://marketplace.gohighlevel.com/docs/ghl/voice-ai/get-action)[**📄️Delete Agent Action** \\
Delete an existing action from a voice AI agent. This permanently removes the action and its configuration.](https://marketplace.gohighlevel.com/docs/ghl/voice-ai/delete-action)
