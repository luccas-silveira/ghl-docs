Documentation for Marketplace API

[**📄️Migrate external authentication connection** \\
Migrates an external authentication connection credentials (basic or oauth2) for a specific app and location. This endpoint validates the app configuration, stores credentials safely in CRM's native encrypted storage. With this the lifecycle of the token is managed by CRM.](https://marketplace.gohighlevel.com/docs/ghl/marketplace/migrate-connection)
